# NayaAksara AI Engineer

Bagian ini berisi pekerjaan AI Engineer untuk proyek NayaAksara.

## Fokus AI Engineer

1. Menyiapkan struktur dataset.
2. Membuat pipeline preprocessing gambar.
3. Membuat script pengecekan kualitas dataset.
4. Membuat baseline CNN.
5. Membuat training pipeline.
6. Membuat evaluasi model.
7. Membuat inference API untuk integrasi dengan backend.
