# Dataset Source - NayaAksara AI

Dataset utama proyek NayaAksara saat ini disimpan di Google Drive tim, bukan langsung di GitHub.

## Alasan Dataset Tidak Disimpan di GitHub

Dataset gambar berpotensi memiliki ukuran besar dan jumlah file yang banyak. Oleh karena itu, GitHub hanya digunakan untuk menyimpan source code AI, struktur folder, template metadata, dokumentasi sumber dataset, serta script preprocessing, training, evaluasi, dan inference.
